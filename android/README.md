# Android app — GLUAY GLUAY PRO

## Current implemented foundation
- Native Kotlin + Jetpack Compose application.
- Home Studio project library backed by Room.
- Create, list, open and delete project records.
- Video selection and Media3 local preview.
- Import audio, extract an audio stream from a video, and record voice-over.
- Store project metadata and selected media references locally; media generated by recording/extraction is stored in app-private project storage.
- Read media duration metadata to populate project clip source ranges.

## Build environment
- Android Studio with JDK 17.
- Android SDK Platform 37 and Build Tools 37.0.0.
- Gradle 8.11.1 or compatible Gradle 8.x supported by Android Gradle Plugin 8.10.1.
- Open the `android/` directory as the Android project (it contains `settings.gradle.kts`).
- Allow Gradle sync to complete, then select the `app` run configuration.

## Current limitations — do not mistake the foundation for a finished editor
- Multitrack timeline editing UI and timeline-to-preview synchronization are not complete.
- Split/trim/move/delete operations exist only in the timeline model and are not yet wired into the app workflow.
- Audio mixing, effects rendering, subtitles, keyframes, tracking, chroma key and final export are not complete.
- HDR/10-bit/120 FPS output is not claimed or verified.
- Build and physical-device tests are pending.

## Verification
A GitHub Actions workflow at `.github/workflows/android-build.yml` attempts a debug APK build for Android code changes. A green workflow is required before calling the source build-ready. A physical-device run is still required for media picker URI persistence, recording, playback and app lifecycle behavior.
